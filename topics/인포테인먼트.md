# 인포테인먼트

최근 갱신: 2026-08-24

자동차 실내의 내비게이션·스마트폰 연결·오디오·콘텐츠·차량용 앱 플랫폼 변화를 누적한다.

## 현재 흐름
- 인포테인먼트는 고정 기능 묶음에서 차량 데이터·외부 앱·승객 반응을 연결하는 앱 플랫폼으로 확장되고 있다.
- [Hyundai](../brands/Hyundai.md)·[Kia](../brands/Kia.md)는 `Pleos Connect` 기반 차량용 앱을 실제 시연 가능한 프로토타입으로 구현하고 서비스화·차량 적용 가능성을 검토하는 단계에 들어갔다.
- 대표 사례 `TaleSync`는 실시간 주행 데이터와 아동 반응을 연결하는 인터랙티브 오디오 서비스로, 차량 상태 데이터를 콘텐츠 경험에 직접 사용하는 방향을 보여준다.
- 앱 생태계 확대와 함께 운전 중 실행 제한, 알림 우선순위, 개인정보·아동 데이터, 앱 권한 관리가 새로운 사용성·안전 과제가 된다.
