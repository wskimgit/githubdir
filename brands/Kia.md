# Kia 자동차 실내 Wiki

최근 갱신: 2026-08-24

## 현재 실내 전략
보급형 EV에서도 다중 디지털 HMI를 유지하면서, `Pleos Connect`를 차량 데이터·외부 앱·승객 경험을 연결하는 앱 플랫폼으로 확장하는 방향이 구체화되고 있다. 기존 대형 SUV에서는 전동시트 안전 신뢰성이 핵심 품질 이슈로 부상했다.

## Pleos Connect 앱 생태계
- 2026-08-20~21 Hyundai와 공동 개최한 첫 차량용 앱 해커톤 `24H Code Race`에서 안전·헬스케어·엔터테인먼트·게이미피케이션 앱 프로토타입을 제작했다.
- 대상 `TaleSync`는 실시간 주행 데이터와 아동 반응을 연동하는 인터랙티브 오디오 서비스다.
- 2026-08-24 기준 수상작의 서비스화·차량 적용 가능성을 검토 중이며 양산 기능 확정 단계는 아니다.

## 모델

### EV3
- 2027 미국형은 12.3인치 계기판 + 5.3인치 공조 화면 + 12.3인치 인포테인먼트를 결합한 약 30인치 디지털 영역을 사용한다.
- 무선 Apple CarPlay·Android Auto, 무선 충전, 상위 트림 Harman/Kardon 오디오를 제공한다.
- 저가 EV에서도 디지털 HMI와 연결성을 기본 상품성으로 유지하는 사례다.

### Telluride
- 2020~2024 일부 차량의 앞좌석 전동 슬라이드 스위치 손상·정렬 불량이 모터 지속 구동과 과열·화재 위험으로 이어질 수 있다.
- 개선 조치는 전자 퓨즈 어셈블리 추가다.
