# Tesla

최근 갱신: 2026-08-23

Tesla의 실내 디자인·HMI·사용성·안전 변화를 누적한다.

## 현재 이슈

### Model 3 / Model Y / Model S / Model X
- 중국에서 약 298만 대가 [비상 도어 릴리스](../topics/비상-도어-릴리스.md) 식별성 관련 리콜 대상이다.
- 기계식 비상 손잡이에 경고 표식을 추가하고 일부 차량은 사고 후 창문 하강 전략을 OTA로 개선한다.

### Model 3 / Model Y — 운전자 모니터링
- 중국산 차량 약 274만 대에서 기존 스티어링휠 토크 감지에 실내 카메라 기반 운전자 주의 모니터링을 추가한다.
- 운전자 상태 감지가 조향 입력 확인에서 시선·주의 상태 감지로 확대되는 사례다.
